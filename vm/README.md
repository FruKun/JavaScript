# виртуальная машина
## Постановка задачи
Требуется
1. придумать собственный низкоуровневый язык, выразительные способности которого
будут достаточны для решения простых вычислительных задач;
2. написать на этом языке программу вычисления факториала натурального числа и
программу нахождения наибольшего общего делителя двух натуральных чисел;
3. написать на JScript виртуальную машину исполняющую программы, написанные на
разработанном языке.  

Подробнее: "Солодушкин Святослав Игоревич, Учебное пособие по дисциплине скрипты" глава 2
## запуск программы
```sh
node vm.js args # количество аргументов зависит от алгоритма в alg.txt
```
## alg.txt
### в файле приведен пример алгоритма поиска наибольшего общего делителя
### запуск 
```sh
node vm.js 100 50
```
### ключевые слова известные виртуальной машине

* разделение между командами - \n или пробел
0. **input {num}** - прочитать аргументы переданные из командной строки и записать в {num} ячейку памяти 
0. **out {num}** - вывести в консоль значение из ячейки памяти
0. **write {str}** - вывести в консоль {str}
0. **goto {metka}** - перейти к {metka} ячейке памяти
0. **assign {num1} {num2}** - записать в ячейку {num1} значение ячейки {num2}
0. **assignn {num1} {num2}** - записать в ячейку {num1} значение {num2}
0. **sum {1} {2} {3}** - сумму значений из ячеек {1} и {2} записать в ячейку {3}
0. **sumn {1} {2} {3}** - сумму значения из ячейки {1} и значения {2} записать в ячейку {3}
0. **sub {1} {2} {3}** - разность значений из ячеек {1} и {2} записать в ячейку {3}
0. **subn {1} {2} {3}** - разность значения из ячейки {1} и значения {2} записать в ячейку {3}
0. **div {1} {2} {3}** - частное значений из ячеек {1} и {2} записать в ячейку {3}
0. **divn {1} {2} {3}** - частное значения из ячейки {1} и значения {2} записать в ячейку {3}
0. **rem {1} {2} {3}** - остаток от деления значений из ячеек {1} и {2} записать в ячейку {3}
0. **remn {1} {2} {3}** - остаток от деления значения из ячейки {1} и значения {2} записать в ячейку {3}
0. **mult {1} {2} {3}** - произведение значений из ячеек {1} и {2} записать в ячейку {3}
0. **multn {1} {2} {3}** - произведение значения из ячейки {1} и значения {2} записать в ячейку {3}
0. **abs {1} {2}** - записать абсолютное значение ячейки {1} в ячейку {2}
0. **if {1} {==|<|>} {2}** - после if всегда идет el, сравниваются значения в ячейках {1} и {2}, если условие верное то выполняется команда идущая сразу после el, если неверное то выполняется el
0. **ifn {1} {==|<|>} {2}** - после ifn всегда идет el, сравниваются значение в ячейке {1} и значение {2}, если условие верное то выполняется команда идущая сразу после el, если неверное то выполняется el
0. **metka {str}** - запомнить позицию с названием {str}
0. **el {1}** - пропустить следующее количество ячеек {1} (длина следующей команды (goto end = длина равна 2))
0. **exit** - завершить выполнение программы
